# Online Examination System

This project is a Java-based console application developed as part of the Oasis Infobyte Java Development Internship.

## Project Description
The Online Examination System allows users to log in, update their profile, attend an online exam, and view their results. The project includes a timer-based examination system with automatic submission functionality.

## Features
- User Login Authentication
- Profile and Password Update
- Multiple Choice Questions
- Timer-Based Online Examination
- Automatic Exam Submission
- Result and Score Display
- Console-Based User Interface

## Technologies Used
- Java
- Timer and TimerTask
- Arrays
- OOP Concepts
- Scanner Class

## How to Run
1. Open the project in any Java IDE.
2. Compile the program.
3. Run the `OnlineExamination.java` file.
4. Login and start the examination.
